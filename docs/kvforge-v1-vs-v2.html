Storage Tiers — Three-Level Architecture  new in V2
Enhanced Tier
Per-token KV sequences on disk
TurboQuant compressed (3-bit keys / 2-bit values)
Qdrant payload: embedding + mean-pool blob + kv_token_path
Mean-pool blob kept as instant fallback
~15 MB/chunk · 4.4× smaller than float16 per-token
Active Tier
Mean-pooled KV blob in Qdrant payload
Identical to V1 storage
Default path for all new chunks
kv_token_path = null
~131 KB/chunk · same as V1
Archive Tier
Embedding + pointer in Qdrant (still retrievable)
kv_cache blob cleared — saves payload storage
Text in user's chosen archival backend (S3 / local / etc.)
Retrieved via text-in-context fallback only
~8 KB in Qdrant + archived text
