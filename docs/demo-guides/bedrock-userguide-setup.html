What this demo does
Builds a technical documentation RAG system over the AWS Bedrock User Guide. Users can ask questions about Bedrock APIs, model providers, pricing, and integration patterns — and get answers grounded in the official documentation. This demonstrates KVForge for enterprise technical support and internal developer tooling.
📦
Dataset: The Amazon Bedrock User Guide PDF (~500 pages). Download it from the AWS documentation site: docs.aws.amazon.com/bedrock/latest/userguide/ → "Download PDF". Place it at examples/usecase4_bedrock_userguide/data/amazon-bedrock-user-guide.pdf. This is a PDF-only use case — there is no HuggingFace dataset for it.
🎯
Goal: After setup, questions like "How do I enable model access in Bedrock?", "What models support streaming?", or "What is the Bedrock pricing for Claude Sonnet?" are answered with citations from the official docs.
💡
Use case: Internal developer knowledge bases, documentation chatbots, and automated support ticket triage are all natural applications of this demo pattern.

Alternative: CLI Setup
Index the Bedrock docs from the command line, using either HuggingFace or local PDFs.
Full CLI walkthrough (PDF source)
export HF_TOKEN=hf_your_token_here   # required for Llama (gated model)
CONFIG=examples/usecase4_bedrock_userguide/config.json
FAQS=examples/usecase4_bedrock_userguide/faqs.json
PDF=examples/usecase4_bedrock_userguide/data/amazon-bedrock-user-guide.pdf

# 1. Place the PDF (download from AWS docs site first)
mkdir -p examples/usecase4_bedrock_userguide/data
# cp ~/Downloads/amazon-bedrock-user-guide.pdf $PDF

# 2. Index the PDF (uses mxbai-embed-large-v1 @ 1024-dim per config.json)
python -m pipeline.kv_indexer --config "$CONFIG" index "$PDF"

# 3. Compute KV tensors
python -m pipeline.kv_indexer --config "$CONFIG" compute-kv

# 4. Train (faqs.json is pre-generated and included in the repo)
python -m pipeline.lora_trainer --config "$CONFIG" --faqs "$FAQS"

# 5. Recompute KV with updated LoRA weights
python -m pipeline.kv_indexer --config "$CONFIG" compute-kv

# 6. Evaluate PRS
python -m pipeline.prs_evaluator --config "$CONFIG" --faqs "$FAQS" --sample 30

# 7. Query
python ask.py --config "$CONFIG" "What is Amazon Bedrock?"
python ask.py --config "$CONFIG" "Which foundation models are available in Bedrock?"
python ask.py --config "$CONFIG" "How do I enable model access in Bedrock?"
