3

4
Step 1: Select Data Source & Vector Database (Weaviate)
SEC EDGAR 10-K and 10-Q filings will be stored in Weaviate for semantic search.
👉
Click the Connect Vector Database source card.
👉
In the VDB grid, click Weaviate.
✍️
Enter: Endpoint: http://localhost:8080 (or your Weaviate Cloud URL). Class: SECFiling.
👉
Click Next →.
TODO — Not yet in KVForge Studio UI
⚠There is no 'EDGAR API' data source option in the wizard. Select 'Connect Vector Database', configure Weaviate, then populate via CLI: python -m pipeline.kv_indexer --config uc_config.json index edgar://AAPL/10-K. The EDGAR full-text search endpoint is free and does not require authentication.

Steps 4–6: GPU, Fine-Tuning & Launch

👀
Review configured connectors and their last sync timestamps.
