What this demo does
Builds a reading comprehension RAG system from the Stanford Question Answering Dataset (SQuAD v1.1). The corpus contains 87,000+ Wikipedia paragraph + question + answer triples. This is the standard academic benchmark for extractive QA, making it ideal for testing KVForge's retrieval and phase-advancement capabilities.
📦
Dataset: rajpurkar/squad_v2 on HuggingFace. 130,319 training examples from Wikipedia passages — includes both answerable questions and unanswerable ones (added in v2). The setup script skips unanswerable questions for the FAQ training set.
🎯
Goal: After setup, the system answers factoid questions from Wikipedia passages. This is a great benchmark use case because SQuAD v2 has official evaluation metrics (EM, F1) you can run against the standard dev set.
💡
Why SQuAD v2? SQuAD v2 is the canonical reading comprehension benchmark. Using it here lets you compare KVForge Phase 1, 2, and 3 performance against published BERT/GPT baselines. The setup script de-duplicates passages so each Wikipedia context is indexed only once.

Alternative: CLI Setup
Set up SQuAD from the command line.
Terminal commands (current working path — before Studio HF integration)
# 1. Download the dataset and write data/corpus.jsonl + faqs.json
python examples/usecase3_squad/setup.py
# Downloads rajpurkar/squad_v2, de-duplicates contexts, writes:
#   examples/usecase3_squad/data/corpus.jsonl  (2 000 unique passages)
#   examples/usecase3_squad/faqs.json          (50 answerable Q&A pairs)

# 2. Index the local corpus via Studio or CLI:
python -m pipeline.kv_indexer \
  --config examples/usecase3_squad/config.json \
  index examples/usecase3_squad/data/corpus.jsonl

# 3. Train (faqs.json already written by setup.py)
python -m pipeline.lora_trainer \
  --config examples/usecase3_squad/config.json \
  --faqs examples/usecase3_squad/faqs.json

# 4. Query
python ask.py \
  --config examples/usecase3_squad/config.json \
  "What river does the Colorado River empty into?"
