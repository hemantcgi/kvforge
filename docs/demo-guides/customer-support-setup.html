What this demo does
Builds a customer support RAG system from a HuggingFace Q&A dataset. The system learns to answer customer queries using the support history corpus, then advances through KVForge's 3 phases: standard RAG → KV-cache injection → confidence-gated parametric answering.
📦
Dataset: A customer support Q&A dataset from HuggingFace Hub (e.g. bitext/Bitext-customer-support-llm-chatbot-training-dataset). Contains thousands of intent-labeled support exchanges.
🎯
Goal: After setup, queries like "How do I cancel my subscription?" are answered using the indexed support history, with accuracy improving after LoRA fine-tuning.
⏱
Estimated time: 5 min setup · 20-40 min indexing (GPU) · 1-2 hr training

Alternative: CLI Setup
You can also set up this demo entirely from the command line without the Studio UI.
Terminal commands
# 1. Initialize the use-case config
python kvforge.py init --name customer_support

# 2. Index the HuggingFace dataset
python -m pipeline.kv_indexer \
  --config datasource_customer_support.json \
  index hf://bitext/Bitext-customer-support-llm-chatbot-training-dataset

# 3. Generate FAQs (requires GOOGLE_API_KEY)
python -m pipeline.sleep_faq_generator \
  --config datasource_customer_support.json \
  --output customer_support_faqs.json --count 50

# 4. Run LoRA training + PRS evaluation
python -m pipeline.lora_trainer \
  --config datasource_customer_support.json \
  --faqs customer_support_faqs.json

# 5. Ask a question
python -m pipeline.kv_inference \
  --config datasource_customer_support.json \
  "How do I cancel my subscription?"
