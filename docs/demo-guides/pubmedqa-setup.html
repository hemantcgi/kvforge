What this demo does
Builds a biomedical question-answering RAG system from the PubMedQA dataset. The corpus contains 1,000 expert-annotated PubMed research questions with long-form answers derived from abstracts. The model learns to reason over clinical evidence to answer yes/no/maybe research questions.
📦
Dataset: qiaojin/PubMedQA on HuggingFace (config: pqa_labeled, split: train). Contains 1,000 expert-labeled biomedical Q&A pairs with long-form answers derived from PubMed abstracts.
🎯
Goal: After setup, queries like "Does X drug reduce mortality in Y condition?" are answered by retrieving relevant abstracts and generating evidence-grounded responses.
⚠
Note: For production biomedical RAG, consider using BioMistral-7B or a medical-domain fine-tuned model instead of the general-purpose Llama-3.2-3B. The wizard's Domain Presets section (once implemented) will offer BioMistral-7B directly.

Alternative: CLI Setup
Set up PubMedQA from the command line.
Terminal commands (current working path — before Studio HF integration)
# 1. Download the dataset and write data/corpus.jsonl + faqs.json
python examples/usecase2_pubmedqa/setup.py
# Downloads qiaojin/PubMedQA (config: pqa_labeled), writes:
#   examples/usecase2_pubmedqa/data/corpus.jsonl  (1 000 records)
#   examples/usecase2_pubmedqa/faqs.json          (50 Q&A pairs)

# 2. Index the local corpus via Studio or CLI:
#    In Studio: UC detail page → "Run Index" button
#    Or CLI:
python -m pipeline.kv_indexer \
  --config examples/usecase2_pubmedqa/config.json \
  index examples/usecase2_pubmedqa/data/corpus.jsonl

# 3. Generate FAQs (already written by setup.py — skip if present)
# python -m pipeline.sleep_faq_generator ...

# 4. Train + evaluate via Studio or CLI
python -m pipeline.lora_trainer \
  --config examples/usecase2_pubmedqa/config.json \
  --faqs examples/usecase2_pubmedqa/faqs.json

# 5. Query
python ask.py \
  --config examples/usecase2_pubmedqa/config.json \
  "Does metformin reduce cardiovascular mortality in type 2 diabetes patients?"
