KVForge Studio — Step-by-step setup guide

LLM: BioMistral-7B

Phase: 1 → 3
1
Sign In to KVForge Studio
Open your browser and navigate to the Studio login page.
🔶
Open http://localhost:8080/auth/login in your browser.
✍️
Enter your credentials and click Sign In.
🟢
You will be redirected to the Studio Hub on success.
KVForge Studio login page
2
Studio Hub Overview
The hub displays all use cases. Start fresh or return to an existing one.
👀
Review the sidebar navigation: Use Cases, Addons, Connectors.
👉
Click + New Use Case to launch the wizard for the FDA drug labels demo.

Studio Hub
3
Open the New Use Case Wizard
The 7-step wizard configures all aspects of your use case.
👉
Click + New Use Case or the dashed card in the hub.
✅
The wizard opens on Step 1 — Data Source.
Wizard Step 1 — Data Source
4
Step 1: Select Data Source & Vector Database (Milvus)
FDA drug label data will be stored in Milvus for scalable clinical search.
👉
Click the Connect Vector Database source card.
👉
In the VDB grid, click Milvus.
✍️
Enter: Host: localhost, Port: 19530, Collection: fda_drug_labels.
👉
Click Next → to proceed.
TODO — Not yet in KVForge Studio UI
⚠There is no 'openFDA API' data source option in the wizard. Select 'Connect Vector Database' and index FDA content manually via CLI: python -m pipeline.kv_indexer --config uc_config.json index fda://drug/label. Ensure Milvus is running locally or configure a cloud endpoint.
Milvus selected in the VDB grid
5
Step 3: Select LLM Model (BioMistral-7B)
Use a biomedical-domain LLM for accurate drug safety interpretation.
👉
Click through Step 2 (Training Q&A) using defaults.
👉
On Step 3, click the Custom model card.
✍️
Type: BioMistral/BioMistral-7B
👉
Click Next →.
TODO — Not yet in KVForge Studio UI
⚠BioMistral-7B is not in the preset model list. Use the Custom model card. Requires a HuggingFace token and approximately 14 GB VRAM with 4-bit quantization (BitsAndBytes). Set HF_TOKEN in your environment before launching.
Custom model input — BioMistral-7B

Steps 4–6: GPU, Fine-Tuning & Launch
Configure GPU assignment, accept fine-tuning defaults, and launch the pipeline.
👉
Step 4: select an available GPU (green = free).
👉
Step 5: leave LoRA parameters at defaults.
✅
Step 6: review config and click Launch.
Model selection step (for illustration)

Set Up FDA Data Sync via Connectors
Configure ongoing sync to keep drug label data current.
👉
In the sidebar, click Addons → Connectors.
👀
The Connectors page shows all active data connectors.
TODO — Not yet in KVForge Studio UI
⚠FDAConnector is not in the Add Connector dialog. Supported types are: GDrive, S3, SharePoint. FDA data sync must be run via CLI: python -m pipeline.kv_indexer --config cfg.json index fda://drug/label --delta. The openFDA API is rate-limited to 240 requests/minute without an API key. Register at https://open.fda.gov/apis/authentication/ for higher limits.
