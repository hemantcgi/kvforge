# RAFT Phase-2 co-judge — reproducibility bundle

Blind, same-session Opus co-judge of the 5 RAFT Phase-2 arms on 481 UC4 facts.
These artifacts regenerate the **computed statistical core** of
`results/knowledge/uc4/raft_phase2_verdict.json`.

Metric: `coverage@0.5 = (CORRECT + PARTIAL) / 481`. Arms: `R0` base+top-5, `R1`
promo adapter+top-5, `R2` RAFT adapter+top-5, `R3` RAFT closed-book, `R1cb` promo
adapter closed-book (prior deterministic dump, re-judged fresh in this session).
Fact strata: hit=290 / miss=191 (gold chunk in top-5), clean=406 / leaked=75.

## Files

| Path | Committed? | What |
|---|---|---|
| `cojudge_p2_key.json` | yes (~388 KB) | un-blinding key (shuffled label → arm), kept **outside** `shards/` |
| `cojudge_p2_facts_meta.json` | yes (~48 KB) | per-fact `chunk_id` / `hit` / `answer_in_context` / `leaked` flags |
| `shards/` | yes (~364 KB) | blinded, grouped-by-fact, deduped judge **inputs** — see [`shards/README.md`](shards/README.md) |
| `judge_out/` | yes (~44 KB) | fresh-Opus **grades** (canonical judged record) — see [`judge_out/README.md`](judge_out/README.md) |
| `preds/` | **samples only** | per-arm prediction dumps — large generated data, **not committed**; 3-record samples + how-to in [`preds/README.md`](preds/README.md) |

Each sub-folder carries its own README documenting its schema and how it is
produced/consumed. The large prediction dumps (~5.6 MB) are **not** checked in:
they are regenerable with `tools/dump_rag_preds.py` (and are in the EC2 backup),
and the pre-registered verdict does not need them.

## Pipeline

```bash
# 1. Build the blind shards + key + meta from the full prediction dumps.
#    Needs the full preds/ (regenerate or point at the backup) AND --train (the
#    ~9.5 MB packed RAFT set, backup-only) for the per-fact leak flag.
python tools/cojudge_build_phase2.py --preds-dir <full_preds> --train <faqs_raft.json>

# 2. (manual) Grade each blind shard with a fresh Opus subagent -> judge_out/.
#    Non-deterministic; the committed judge_out/ is the canonical graded record.

# 3. Score the pre-registered verdict (coverage, PRIMARY R2-vs-R0, interaction DiD,
#    clean/leaked, secondaries, confounds). Needs NO preds.
python tools/cojudge_score_phase2.py

# 4. Append the advisor follow-ups (R2-vs-R1, hit-side interference, mechanism
#    discriminating-baseline; plus q/gold + length parity when full preds present).
python tools/cojudge_score_extended_phase2.py                      # from committed data
python tools/cojudge_score_extended_phase2.py --preds-dir <full_preds>  # adds parity/length fields
```

Determinism (`numpy`-seeded bootstraps, seed=42), verified:
- Step 1 reproduces the committed `shards/` + `key` + `meta` **byte-for-byte**.
- Step 3 + step 4 reproduce **20 grade-derived verdict fields byte-for-byte** from
  the committed small data alone. With the full `preds/` present, step 4 also
  reproduces the 2 preds-derived fields (`qgold_parity`,
  `format_parity_median_pred_words`) → **all 22 computed fields** match.

## Curated fields (NOT regenerated by the scripts)

Three top-level fields in the checked-in verdict were added by later analysis and
are not emitted by `cojudge_score*_phase2.py`:

- `HEADLINE` — prose interpretation of the result.
- `wilcoxon_3level_paired` — pre-registered §8 Wilcoxon on the 3-level graded score
  (R2-vs-R0 p=1.49e-07, R2-vs-R1 p=5.25e-09); confirms the band, does not change it.
- `cross_session_drift` — R1cb coverage here (0.5281) vs the Phase-1 promotion judge
  (0.461), drift +0.067, on byte-identical closed-book text. Only within-session
  deltas are valid; the rubric was reconstructed, not taken verbatim.
