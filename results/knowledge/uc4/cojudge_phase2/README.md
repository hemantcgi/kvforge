# RAFT Phase-2 co-judge — reproducibility bundle

Blind, same-session Opus co-judge of the 5 RAFT Phase-2 arms on 481 UC4 facts.
These artifacts regenerate the **computed statistical core** of
`results/knowledge/uc4/raft_phase2_verdict.json`.

Metric: `coverage@0.5 = (CORRECT + PARTIAL) / 481`. Arms: `R0` base+top-5, `R1`
promo adapter+top-5, `R2` RAFT adapter+top-5, `R3` RAFT closed-book, `R1cb` promo
adapter closed-book (prior deterministic dump, re-judged fresh in this session).
Fact strata: hit=290 / miss=191 (gold chunk in top-5), clean=406 / leaked=75.

## Files

| Path | What |
|---|---|
| `preds/phase2_preds_{R0,R1,R2,R3,R1cb}.jsonl` | per-arm prediction dumps (`R1cb` was renamed from `rwscale_preds_promo_allLinear.jsonl`) |
| `shards/shard_00..09.json` | blinded, grouped-by-fact, within-fact-deduped judge inputs (no arm labels) |
| `cojudge_p2_key.json` | un-blinding key (shuffled label → arm), kept **outside** `shards/` |
| `cojudge_p2_facts_meta.json` | per-fact `hit` / `answer_in_context` / `leaked` flags |
| `judge_out/shard_00..09.json` | the fresh-Opus grades (CORRECT / PARTIAL / INCORRECT per fact per label) |

## Pipeline

```bash
# 1. Build the blind shards + key + meta from the prediction dumps.
#    --train (the ~9.5 MB packed RAFT set) is needed ONLY for the per-fact leak
#    flag; it lives in the EC2 backup and is not committed (the resulting meta is).
python tools/cojudge_build_phase2.py --train <faqs_raft.json>

# 2. (manual) Grade each blind shard with a fresh Opus subagent -> judge_out/.
#    Non-deterministic; the committed judge_out/ is the canonical graded record.

# 3. Score the pre-registered verdict (coverage, PRIMARY R2-vs-R0, interaction DiD,
#    clean/leaked, secondaries, confounds).
python tools/cojudge_score_phase2.py

# 4. Append the advisor follow-ups (q/gold parity, R2-vs-R1, hit-side interference,
#    mechanism discriminating-baseline, length parity).
python tools/cojudge_score_extended_phase2.py
```

Steps 1, 3 and 4 are deterministic and reproduce the committed shards/key/meta and
all 22 computed verdict fields byte-for-byte (`numpy`-seeded bootstraps, seed=42).

## Curated fields (NOT regenerated by the scripts)

Three top-level fields in the checked-in verdict were added by later analysis and
are not emitted by `cojudge_score*_phase2.py`:

- `HEADLINE` — prose interpretation of the result.
- `wilcoxon_3level_paired` — pre-registered §8 Wilcoxon on the 3-level graded score
  (R2-vs-R0 p=1.49e-07, R2-vs-R1 p=5.25e-09); confirms the band, does not change it.
- `cross_session_drift` — R1cb coverage here (0.5281) vs the Phase-1 promotion judge
  (0.461), drift +0.067, on byte-identical closed-book text. Only within-session
  deltas are valid; the rubric was reconstructed, not taken verbatim.
