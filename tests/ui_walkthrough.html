Role-Based Access Control

RBAC enforcement: admin accesses connectors page → logout → viewer gets 403 on connectors → viewer can still see the hub.

Step 1 Admin user can access the /studio/connectors page — sees full UI with Add button.
Step 2 After logout, session is cleared and user is redirected to the login page.
Step 3 Viewer role is denied access to /studio/connectors — server returns 403 Forbidden.
Step 4 Viewer can still access the studio hub — role restriction applies only to sensitive pages (connectors) not the general dashboard.
