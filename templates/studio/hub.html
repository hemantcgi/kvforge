🖥 Connect a GPU
KVForge needs an NVIDIA GPU for KV tensor computation, LLM inference, and LoRA fine-tuning.
AWS EC2 (Recommended)
Local NVIDIA GPU
Remote vLLM API
1
Launch an EC2 g5.xlarge instance
The A10G (24 GB VRAM) is the recommended GPU. Use the Deep Learning AMI (Ubuntu 22.04) — it ships with CUDA 12, nvidia-smi, and PyTorch pre-installed.
aws ec2 run-instances \ --image-id ami-0c55b159cbfafe1f0 \ --instance-type g5.xlarge \ --key-name your-keypair \ --security-group-ids sg-xxxxxxxx \ --block-device-mappings '[{"DeviceName":"/dev/sda1","Ebs":{"VolumeSize":100}}]'
💡 Tip: Use a Spot instance for ~70% cost savings. Request a spot instance through the EC2 console or add --instance-market-options MarketType=spot to the command above.
2
SSH tunnel to expose port 8080
Forward the KVForge Studio port from the EC2 instance to your local machine so you can use the browser UI.
ssh -i your-keypair.pem -L 8080:localhost:8080 ubuntu@<EC2-PUBLIC-IP>
3
Clone and start KVForge on the instance
git clone https://github.com/your-org/kvforge.git cd kvforge pip install -r requirements.txt python kvforge_portal.py --port 8080
4
Verify GPU visibility
Run this on the EC2 instance to confirm the GPU is visible to KVForge.
nvidia-smi --query-gpu=name,memory.total --format=csv,noheader
1
Verify NVIDIA driver and nvidia-smi
KVForge requires at least 16 GB VRAM (24 GB recommended). Supported GPUs: RTX 3090/4090, A10G, A100, H100.
nvidia-smi
2
Install CUDA 12 and PyTorch
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
3
Confirm KVForge can see your GPU
python -c "import torch; print(torch.cuda.get_device_name(0))"
Expected output: NVIDIA GeForce RTX 4090 (or your card name). If you see an error, your CUDA installation may be incomplete.
4
Restart KVForge Studio
After confirming GPU access, restart the portal and return to this page — the GPU status card should show your device.
python kvforge_portal.py --port 8080
1
Deploy vLLM on a remote GPU host
Run vLLM on any GPU server accessible over the network. KVForge will call its OpenAI-compatible API for LLM inference steps.
pip install vllm python -m vllm.entrypoints.openai.api_server \ --model meta-llama/Llama-3.2-3B-Instruct \ --port 8090
2
Add the vLLM URL in KVForge Settings
Open Settings → LLM section and paste the remote vLLM API URL. KVForge will route inference calls to this endpoint.
📌 Go to Settings → LLM → vLLM API URL and enter:
http://<GPU-HOST-IP>:8090/v1
3
Note: KV tensor computation still needs local GPU
The remote vLLM API handles LLM inference, but Phase 2 KV tensor pre-computation requires direct GPU access (CUDA). For Phase 1 text RAG only, the remote API is sufficient.
4
Configure the vLLM URL per use case
Each use case can have its own vLLM endpoint set during wizard setup (LLM step → "vLLM URL" field), overriding the global setting.
After connecting, refresh this page to detect your GPU.
